# Data Analysis Report

## 1. Executive Summary

This report provides a comprehensive analysis of a dataset consisting of 1000 movies, scrutinizing various aspects such as data quality, distribution of user rating scores, and trends over time. Significant findings indicate a weak positive correlation between movie ratings and user rating scores, and that movies released in recent years tend to have higher average user rating scores. However, the analysis faced challenges due to data quality issues, particularly the high percentage of null values in key columns.

## 2. Dataset Overview

The dataset comprises 1000 rows and 7 columns, capturing information about movies such as titles, user rating scores, and release years. Key highlights include:

- The `title` column shows high cardinality with 496 unique entries, indicating a diverse dataset.
- Three distinct values categorize `user_rating_size`, suggesting limited variability in how user ratings are aggregated.

## 3. Data Quality

Several issues were identified which could impact data analyses:

- **High Null Percentage**: `user_rating_score` contains 39.5% null values, undermining the accuracy of analyses related to this metric.
- **Data Type Inconsistencies**: The `ratingdescription` column is incorrectly classified as 'int64', suggesting a misclassification of data types.
- **Null Entries in Categorical Data**: `ratinglevel` contains 5.9% null values, which might obscure categorical data patterns.
- **Cardinality and Range Concerns**: Low cardinality in `user_rating_size` and out-of-range values in `release_year` were noted, though their impact is deemed less urgent.

## 4. Key Findings

### Confirmed Findings

1. **Correlation Between Ratings and Scores**: Movies with higher ratings tend to have higher user rating scores. A correlation coefficient of 0.224 indicates a weak positive relationship. 

2. **Impact of Release Year**: Recent years such as 2016 and 2017 show higher average user rating scores, with scores of 85.9715 and 87.9567, respectively, compared to earlier years.

3. **Variation by Rating Level**: Different 'ratinglevel' categories display significant variation in user rating scores, with averages ranging from 56.0 to 97.0 across levels.

### Refuted Hypotheses

The analysis refuted several hypotheses, including:

- Movies with a 'PG-13' rating level did not show a wider distribution of user rating scores.
- Larger `user_rating_size` did not correlate reliably with consistent or higher user rating scores.

## 6. Recommended Next Steps

To enhance the reliability and depth of future analyses, the following steps are recommended:

- **Data Cleaning**: Prioritize addressing high null percentages in `user_rating_score` and resolve misclassification in `ratingdescription`.
- **Data Validation**: Investigate potential data entry errors or misformatted entries in `user_rating_size` and `release_year`.
- **In-depth Analysis**: Further explore the causal factors behind trends identified, particularly the reasons behind score variations in 'ratinglevel' categories.

Implementing these improvements will strengthen data-driven decision-making and enable more robust insights into movie ratings and user perceptions.
